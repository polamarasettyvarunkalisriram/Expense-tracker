# Expense Tracker – Full Stack Web Application

Expense Tracker is a full-stack web application developed to manage daily income and expenses efficiently. The application helps users track transactions, monitor spending, and manage financial records with a secure and responsive interface.

---

# Features

## Authentication
- User Registration
- User Login
- JWT Authentication
- Password Encryption using bcrypt

## Expense Management
- Add Expenses
- Edit Expenses
- Delete Expenses
- Income & Expense Tracking
- Category-Based Transactions
- Date-Wise Expense Monitoring

## Dashboard
- Total Income Display
- Total Expense Display
- Balance Calculation
- Transaction History
- Expense Summary

## UI Features
- Responsive Design
- Dashboard Cards
- Sidebar Navigation
- Clean User Interface
